# 📱 Power BI Mobile Sales Dashboard

## 📌 Project Overview

The **Mobile Sales Dashboard** is an interactive data visualization project developed using Microsoft Power BI to analyze mobile phone sales performance, customer ratings, payment preferences, and sales trends.

The dashboard transforms sales data into meaningful business insights through interactive charts, KPI cards, maps, and filters.

This project was created as part of my Power BI learning journey through the **Skill Course by Satish Dhawale Sir**.

## 🎯 Project Objectives

- Analyze overall mobile sales performance.
- Compare sales across different mobile brands and models.
- Understand customer payment preferences.
- Analyze customer ratings.
- Identify sales trends across different days and months.
- Explore geographical sales distribution across cities.

## 🛠️ Tools & Technologies

- **Microsoft Power BI** — Dashboard development and visualization
- **Power Query** — Data transformation and preparation, if used
- **DAX** — Calculated measures and KPIs, if used
- **Data Visualization** — Interactive charts, maps, and KPI cards

## 📊 Dashboard Features

### 1. Key Performance Indicators (KPIs)
- Total Sales
- Total Quantity Sold
- Number of Transactions
- Average Sales

### 2. Geographical Sales Analysis
Visualizes mobile sales across different cities using a map.

### 3. Monthly Quantity Analysis
Displays monthly sales quantity to help identify changes in sales volume over time.

### 4. Mobile Model Performance
Compares sales performance across mobile models, including iPhone SE, OnePlus Nord, and Samsung Galaxy S21.

### 5. Payment Method Analysis
Shows the distribution of transactions across:
- UPI
- Credit Card
- Debit Card
- Cash

### 6. Customer Ratings
Visualizes customer ratings to understand customer satisfaction patterns.

### 7. Day-wise Sales Analysis
Compares sales performance across different days of the week.

### 8. Interactive Filters
Allows users to filter the dashboard by:
- Month
- Mobile Model
- Brand

## 🚀 How to Use This Project

1. Download or clone this repository.
2. Install Microsoft Power BI Desktop.
3. Open `Mobile_Sales_Dashboard.pbix`.
4. Refresh the data source if necessary.
5. Use the month, mobile model, and brand filters to explore the dashboard.
